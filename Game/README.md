# 简介
本目录下都是一些小游戏，包括球碰撞模拟、太阳系模拟等，均使用Python和Pygame库编写。

# 目录结构
- ball_collision_simulation/: 包含一个使用Pygame编写的球碰撞模拟程序。
- soloar/: 一个太阳系局部模型的模拟程序，展示了太阳、地球和月球的运动。
- fruit_slicing_game/: 一个水果切割小游戏，类似于经典的Fruit Ninja游戏。
- music_player/: 一个简单的音乐播放器应用，支持播放、暂停和切换音乐。
- particle_explosion_demo/: 一个粒子爆炸效果的演示程序。
