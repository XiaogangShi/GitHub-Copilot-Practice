# Calculator Web App

这是一个基于 HTML, CSS, JavaScript 的简易计算器 Web 应用，复刻了 Python (Tkinter) 版本的计算器布局和逻辑。

## 功能特性

- **基本运算**：支持加 (+)、减 (-)、乘 (*)、除 (/) 以及小数运算。
- **网格布局**：采用经典的 4x4 按钮布局。
- **键盘支持**：
  - 数字键和运算符键：直接输入。
  - `Enter` 键：执行计算 (=)。
  - `Backspace` 键：删除最后一个字符。
  - `c` 或 `C` 键：清空输入框。
- **鼠标交互**：
  - 点击按钮进行输入和计算。
  - **双击输入框**可直接清空内容。

## 项目结构

- `index.html`: 定义计算器的 HTML 结构。
- `style.css`: 负责界面样式，模仿桌面应用的简洁外观。
- `script.js`: 处理计算逻辑和事件监听。

## 使用方法

直接在浏览器中打开 `index.html` 文件即可使用。
