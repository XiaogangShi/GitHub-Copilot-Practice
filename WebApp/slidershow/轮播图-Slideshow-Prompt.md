# 3, Final Prompt

 推荐使用的提示词：

请使用 HTML, CSS 和 JavaScript 编写一个 Web 端轮播图（Carousel）应用。请严格按照以下需求实现，确保代码逻辑清晰且可以直接运行。
1. 文件结构与引用：
HTML：主文件，需正确引入名为 slideshow.css 的样式文件和名为 slideshow.js 的脚本文件。
CSS：文件名为 slideshow.css。
JS：文件名为 slideshow.js。
2. 布局与尺寸（CSS）：
整体布局：轮播图容器必须显示在当前浏览器窗口的正中心（水平居中且垂直居中）。建议使用 Flexbox 或 Grid 布局实现 body 的居中对齐。
轮播图尺寸：固定为 宽 800px，高 600px。
超出隐藏：容器需设置 overflow: hidden，确保只显示当前的一张图片。
3. 轮播内容：
轮播图共包含 10 个页面（Slide）。
为了演示效果，每个 Slide 可以使用不同的背景色，并在中心显示 "Page 1" 到 "Page 10" 的文字，或者使用 https://placehold.co/800x600?text=1 这样的占位图片。
4. 切换效果：
动画：必须实现**平滑滚动（Smooth Sliding）**效果。即切换时，图片是横向滑动的，而不是生硬的跳变。
5. 交互与控制功能：
自动播放：每 3 秒自动切换到下一页。
底部指示器（Indicators）：在轮播图内容的正下方中心位置，显示 10 个小圆点。
当前页对应的小圆点需要高亮显示。
点击任意小圆点，轮播图应平滑滚动到对应的页面。
左右切换箭头：在轮播图的左侧和右侧垂直居中位置，分别放置“上一页”和“下一页”的箭头按钮。点击可手动切换。
6. 额外细节：
当鼠标悬停（Hover）在轮播图区域内时，暂停自动播放计时器；鼠标移出后，恢复自动播放。


为什么这样改更好？

修正了“羊”的笔误：我去掉了关于“羊”的描述，改为要求使用“占位图片或带文字的背景色”，这样 LLM 生成的代码不会因为找不到具体的羊图片资源而显示“图片裂开”的图标。
明确了具体的 UI 组件：将模糊的“页面切换功能”拆解为标准的 “底部圆点指示器” 和 “左右箭头”，这是轮播图的标准做法，避免 LLM 瞎猜。
锁定了尺寸：明确 800x600，这决定了 CSS 的写法。
明确了动画逻辑：指定 “平滑滚动”，这会引导 LLM 使用 transform: translateX(...) 配合 transition 属性，或者 CSS Scroll Snap 技术，而不是简单的 opacity 变化。
增加了用户体验细节：特意加上了“鼠标悬停暂停”的要求，这是一个成熟的轮播图必须具备的功能，否则用户刚想点击某个东西图片就滑走了，体验会很差。
