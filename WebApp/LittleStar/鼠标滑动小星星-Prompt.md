# 2, After Gemini 3 Pro first response
优化后的提示词建议

为了得到一个流畅、酷炫且不卡顿的特效，建议使用以下优化后的提示词：
推荐的提示词 (Prompt)：
请使用 HTML5 Canvas 和 JavaScript 实现一个高性能的鼠标跟随粒子特效。
需求细节如下：
页面样式：
背景颜色为纯黑色 (#000)。
Canvas 元素需要覆盖整个浏览器窗口，并随窗口大小改变自动调整（Responsive）。
交互逻辑：
监听鼠标移动事件。当鼠标移动时，在鼠标当前位置生成多个“小星星”粒子。
粒子（星星）外观：
形状：绘制五角星，或者简单的发光圆形点（模拟星尘）。
颜色：随机的彩虹色（使用 HSL 颜色模式，色相随机）。
大小：随机大小，增加层次感。
动画物理效果：
粒子生成后，应具备一个随机的初速度（向四周轻微扩散）。
具备重力效果（粒子会逐渐加速向下坠落）。
消失机制：粒子在移动过程中大小逐渐变小（Shrink）或透明度逐渐降低（Fade out）。
当粒子完全消失或移除屏幕外时，必须从内存中清除，防止内存泄漏。
代码要求：
使用 requestAnimationFrame 实现流畅的动画循环。
代码结构清晰，将粒子封装为 Particle 类。

# 4， Genie 3 Pro response
优化后的提示词建议

建议你使用下面这段更精确的描述，这样 LLM 可以直接生成包含 HTML/CSS 覆盖层的代码，而不必去修改复杂的 Canvas 绘图逻辑：
推荐的提示词 (Prompt)：
请在现有代码的基础上增加一个引导提示功能。
需求细节：
HTML/CSS 实现：请使用一个 HTML 元素（如 <div> 或 <h1>）来显示文字，不要直接画在 Canvas 画布里。
位置与样式：
文字内容：“用鼠标画出你的满天星”。
位置：绝对定位，处于浏览器窗口的正中心。
样式：字体大小 32px，颜色为灰色，字体美观。
关键交互：给该文字元素设置 pointer-events: none 属性，确保鼠标划过文字时，底下的 Canvas 依然能接收到鼠标事件（依然能画出星星）。
动画逻辑：
页面加载后，文字立即显示。
停留 3 秒后，文字开始执行**淡出（Fade Out）**动画（持续时间约 1~2 秒）。
动画结束后，将该 DOM 元素彻底隐藏或从 DOM 中移除。
