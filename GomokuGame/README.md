python main.py# 五子棋游戏 (Gomoku Game)

这是一个功能完善、界面美观的Python五子棋游戏，使用tkinter库创建GUI界面。

## 🎮 功能特点

### 核心功能
- **美观的GUI界面**：棋盘采用木纹色调，15x15网格，带有天元和星位标记
- **双模式支持**：
  - 👥 人人对战：两个玩家轮流落子
  - 🤖 人机对战：与智能AI对战
- **智能AI算法**：
  - 启发式评估函数，综合考虑攻击和防守
  - 评估连珠数量和开放端点
  - 优先攻击，兼顾防守
  - 仅搜索已有棋子周围位置，提高效率
- **游戏功能**：
  - 自动检测五子连珠的胜利条件
  - 支持悔棋功能
  - 最后落子位置高亮显示
  - 棋子带有阴影和高光效果

### 界面特色
- 🎨 精美的棋盘设计（木纹色调）
- 🔴 最后落子红框高亮
- ⚫⚪ 立体棋子效果（带阴影和高光）
- 📊 实时显示当前玩家和游戏模式

## 🎯 游戏规则

1. **基本规则**
   - 黑棋先行，白棋后行
   - 玩家交替在棋盘上落子
   - 率先在横、竖或斜线上连成五个棋子的一方获胜

2. **操作说明**
   - 点击棋盘上的交叉点落子
   - 点击"新游戏"按钮重新开始
   - 点击"人机对战/人人对战"按钮切换模式
   - 点击"悔棋"按钮撤销上一步（AI模式下撤销两步）

## 🧠 AI算法说明

AI使用改进的启发式算法，包括：

### 评分系统
- **五连珠**：100000分（获胜）
- **活四**：10000分（两端开放的四连珠）
- **冲四**：10000分（一端开放的四连珠）
- **活三**：5000分（两端开放的三连珠）
- **眠三**：1000分（一端开放的三连珠）
- **活二**：500分（两端开放的二连珠）
- **眠二**：100分（一端开放的二连珠）

### 策略
1. **攻防平衡**：攻击分数×1.2 + 防守分数
2. **智能搜索**：只评估已有棋子周围2格内的空位，提高效率
3. **优先级判断**：优先进攻，同时兼顾防守关键位置

## 💡 使用技巧

1. **首次落子**：AI模式下，如果是空棋盘，AI会选择中心位置
2. **悔棋功能**：在AI模式下，悔棋会同时撤销玩家和AI的落子
3. **快速重开**：点击"新游戏"立即重置棋盘
4. **切换模式**：切换模式时会自动重置游戏

## 🔧 自定义选项

可以在代码中修改以下常量来自定义游戏：
- `BOARD_SIZE`：棋盘大小（默认15）
- `cell_size`：格子大小（默认35像素）
- `margin`：边距大小（默认40像素）
- 评分常量：调整AI策略
